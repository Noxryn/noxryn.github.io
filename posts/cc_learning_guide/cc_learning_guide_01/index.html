C++ 成长之路 ———— 基础语法篇上

七月 22, 2026 · 3 分钟 · 573 字 · Noxryn · 
C++

前言#

作为一名从事 C++ 开发的菜鸟，谨以此文记录 C++ 的相关语法，巩固知识体系，以此作为本人成长之路上的鉴证。

Hello World!#

代码块#

// helloworld.cc

#include <iostream>  // 头文件

int main()   // main 函数
{
  std::cout << "Hello World!" << std::endl;  
  return 0;  // C++ 中 return 0 可以省略由编译器自动添加
}

上述代码即为最简单的 C++ 程序：

  • 头文件引入标准库<iostream>，这将提供 IO 操作等标准库函数
  • 每个 C++ 程序都包含一个或多个函数，其中必须有且仅有一个名为 main() 的全局函数，程序从此开始
  • 语句作为 C++ 语言中最小的的独立计算单元，绝大多数以 ; 结尾
  • 函数由返回类型、函数名、参数列表、函数体组成，用于完成特定的工作或执行一组操作
  • C++ 程序文件后缀名为 cpp、cc、cxx等，具体由编译器约定

编译、运行#

高级语言编写的代码文件必须由编译器编译链接为可执行文件才能使用，目前主流的编译器有 gcc、clang、msvc。比起纯编译器，直接使用集成编译环境（IDE）更加方便如 Visual Studio、Clion等。
本文重点关注语法，编程环境及工具只简单提及，请自行搭建安装。

本文所有代码皆使用 vscode + wsl 环境使用 g++ 编译运行，c++20 等新特性由于编译器支持限制转而使用 Visual Studio 2026。 命令：

g++ helloworld.cc -o hellowold
./helloworld

语法入门#

标准输入输出对象#

<iostream>库是 C++ 的标准库，命名空间为 std；使用标准库函数需在函数前添加 std:: ，或使用 using 关键字，如新手常见的 using namespace std;。

  • 为避免不必要的冲突，请谨慎且最小影响的使用 using 关键字

标准库定义 IO 对象如下，作用同 C 语言的 scanf 和 printf：

名称IO 对象作用
标准输入cin同字面
标准输出cout同字面
标准错误cerr输出警告和错误消息
标准日志clog输出程序运行时的一般性信息

注释#

注释即直接插入到源代码中的笔记，会被编译器忽略，仅用于记录代码功能，变量含义等辅助信息。
注释对于程序的可读性帮助极大，正所谓程序员最讨厌的两件事:

“1.自己要写注释；2.别人不写注释”

C++ 中存在单行注释和界定符对注释两种：

  1. 单行注释 单行注释以双斜线 // 开始，换行符结束，双斜线右侧的内容被编译器忽略

  2. 多行注释 多行注释顾名思义可以跨越多行，以 /* 开始，*/ 结束，二者之间的内容即为注释 注：注释界定符不能嵌套

示例：

// 单行注释

/*
  多行注释
*/

变量及基本类型#

变量#

定义：变量提供具名的、可供程序操作的存储空间，数据类型决定变量所占内存空间的大小和布局方式。

语法：<type> var_name = value;

int sum = 0 ,value;
string name;

变量使用类型说明符修饰变量名，相同类型的变量名可以以逗号分隔。 定义时可以同步进行初始化。

标识符#

C++ 标识符由字母、数字和下划线组成，且必须以字母或下划线开头，同时区分大小写字母。

注：不要使用 C++ 保留的关键字作为标识符。

初始化#

定义：对象创建时获得特定的值（可以是任意复杂的表达式）。

注：初始化不是赋值，赋值是将对象的当前值擦除后用新值代替。

语法：

int var = 0;
int var = {0};
int var{0}; // C++11 引入列表初始化，即用花括号初始化变量。
int var(0);

若定义时未初始化，则变量被默认初始化（函数体内的内置类型除外），使用未初始化变量将引发未知后果。

声明和定义#

C++ 支持分离式编译，为此变量的声明和定义相区别，声明使变量为程序所知，定义创建与变量名关联的实体。

单纯声明变量而不定义，使用 extern 关键字，且不显示初始化变量。

作用域#

作用域定义变量的生命周期范围。C++ 以花括号分隔作用域，允许嵌套，内层作用域覆盖外层同名变量。

带符号类型和无符号类型#

除布尔类型和扩展精度浮点数外，其它整型具有带符号（signed）和无符号（unsigned）两种。

带符号类型将将首位比特用作符号表示正负，无符号类型则将所有比特用来存储值。

注：字符型被分为 char、signed char 和 unsigned char 三种，但只表示为带符号和无符号两种形式，具体由编译器决定。

  1. typedef 关键字：typedef int INT;
  2. using 关键字：using INT = int;

  • auto 关键字使编译器自动推导变量类型 auto var = 1;
  • decltype 关键字使用表达式类型推断定义比变量的类型 decltype(f()) sum = x;

指针 *#

指针存放对象的地址，实现对对象的间接访问。指针本身为对象，允许对指针赋值和拷贝，使用时应注意初始化，避免野指针。

指针使用时以取地址符 & 获取地址，以解引用符 * 访问对象。

int var = 1;
int *pl = nullptr; // nullptr 取代 NULL 初始化指针
pl = &var;
cout << *pl
  • 空指针：不指向对象的指针，使用 nullptr初始化
  • void* 指针：可以存放任意对象的地址

引用 &#

引用即给变量起别名 等价于 指针常量（int * const p;），定义时引用与初始值绑定且必须初始化，初始化后无法重新绑定。

  • 左值引用：常规引用，表示对象的身份 避免参数拷贝
  • 右值引用： 必须绑定到右值(临时对象)的引用，表示值 可实现转移语义和精确传递，达到消除不必要的对象拷贝和更简洁明确地定义泛型的目的
int &refVal = var;

const 限定符#

const 关键字修饰的变量，创建后值不能改变，变量必须初始化。

注：默认状态下，const 对象仅在文件内有效。

1.修饰变量#

  • 定义常量，同宏定义类似 宏常量：#define 常量名 常量值
    常类型：使用类型修饰符const说明的类型，值不能被改变, const 数据类型 常量名 = 初始值;
  • 类型检查
    1. const常量具有类型，编译器可以进行安全检查
    2. 宏常量具体类型由字面量和运算符结果类型相关，不进行安全检查
    3. const定义的变量只有类型为整数或枚举，且以常量表达式初始化才能作为常量表达式
  • 防止修改

注：常量初始化后不能修改，且定义时必须初始化

const 在确定初始值时是编译器常量，当然在某些情况也有可能退化为运行时常量
constexpr 更加严格，编译器保证 constexpr 必须是编译期常量，并且 constexpr 可修饰函数使其在编译期计算。所以 constexpr 更像是 #define

注：mutable 关键字可以使常函数修改参数

注：const对象默认为文件局部变量,非const变量默认为extern。要使const变量能够在其他文件中访问，必须在文件中显式地指定它为extern

2.修饰指针#

const int* a;         // 指向常量的指针，底层const - 值不能改变 
int * const a;        // const 指针,顶层const     - 指向不能改变 
const int * const a;  // 指向const对象的const指针

注：

  • 所谓值不能改变是指不能通过指针进行修改
  • const指针必须进行初始化

3.修饰引用#

对 const 的引用即常量引用，const int &r = var;，不能通过引用改变对象的值。

4.修饰函数#

修饰函数返回值#

const int func();  // 无意义
const int* func(); // 值不变
int* const func(); // 指向不变

修饰函数参数#

void func(const int var);  // 传入形参，无意义
void func(int* const var); // 同上

void func(const int* var); // 防止修改变量
void func(const string& s); // 增加效率同时防止修改

注；仅对非内部数据类型的输入参数，将“值传递”的方式改为“const 引用传递”，可提高效率

5.修饰类#

任何不会修改数据成员的函数都应该声明为**const类型**,称常成员函数

注：

  • 只有常成员函数才有资格操作常量或常对象，没有使用const关键字进行说明的成员函数不能用来操作常对象
  • 类中的const成员变量必须通过初始化列表进行初始化
  • const对象只能访问const成员函数,而非const对象可以访问任意的成员函数,包括const成员函数

static#

由 static 关键字修饰的变量称静态变量，其具备共享数据、编译时分配内存、类内声明，类外初始化、类名可直接访问的特点，其中静态成员函数只能访问静态成员变量

当变量使用 static 关键字修饰时，空间将在程序的生命周期内分配，且只分配一次

注：类中的静态变量由对象共享，但不能使用构造函数初始化

注；static 关键字修饰的变量将限定访问范围在本文件当中
