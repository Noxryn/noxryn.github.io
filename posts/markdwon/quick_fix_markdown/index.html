5 分钟速通 Markdown

Markdown 语法速查速记，博客文章编写语法，程序员必备 Readme

前言#

本文对常用 Markdown 语法的进行了归纳总结，仅供参考

Markdown 语法简单，只需记忆少量标记即可愉快使用，个人建议花少量时间了解语法后直接练习上手

Markdown是什么？#

Markdown 是一种轻量级的标记语言，可用于在纯文本文档中添加格式化元素。

Markdown 由 John Gruber 于 2004 年创建，如今已成为世界上最受欢迎的标记语言之一。

基本特性：

  • 专注于文字内容
  • 纯文本，易读易写，可以方便地纳入版本控制
  • 语法简单，能轻松在码字的同时做出美观大方的排版

注：
尽管 Markdown语法被广泛支持，但

实际上每个 Markdown 应用程序都实现了稍有不同的 Markdown 语法

对此只能在使用中自行注意。

使用 Markdown 格式书写时，文件后缀为 .md

注：

  • 文章基于 Markdown 编辑器书写，即时渲染
  • 标题前有几个#即为几级标题
  • Markdown 中段落使用空白行分段，换行应键入两个空格后回车
  • 代码语法为单引号，代码块语法为三重单引号
  • 代码块语法外出现单引号皆为使用代码语法保持文章显示正确
  • Markdown 支持 HTML 语法，原生语法不支持的功能，可用 HTML 语言进行拓展

了解上述表格中的语法基本上就足够使用了，很简单不是吗！
