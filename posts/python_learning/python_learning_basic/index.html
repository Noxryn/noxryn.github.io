Python 基础语法

Python 基础语法 v0.1

Python

前言#

Python 是一种解释型的面向对象语言，简单易学，应用广泛。以下是 Python 的基本语法及使用示例。

Hello World!#

message = "Hello World!"
print(message)

标识符#

  • 只能包含字母、数字和下划线，不能以数字开头，且不能使用关键字
  • 变量名不能包含空格
  • 字母区分大小写
  • 无长度限制

注释#

  1. 单行注释：同 C/C++ 等不同，Python 中使用 # 标识表示注释，# 后的内容会被解释器忽略
  2. 多行注释：由三个引号（单引号或双引号）包围的文本 ，多行注释不能嵌套
  3. 文档字符串："""<text>""" ，用于描述函数功能，Python 可以使用文档字符串生成有关程序中函数的文档，通过 __doc__ 属性直接访问
  4. Python 提供 inspect 模式提取文档内容

缩进#

Python 最具特色的就是使用缩进而不是 {} 表示代码块。同一代码块必须包含相同的缩进空格数！

Python 中使用空行分隔函数，表示新代码的开始。

输出#

语法：print(str)，默认换行，不换行 print(str,end="")

变量和数据类型#

变量#

语法：var = val

  1. Python 中变量不需要声明，但使用前必须赋值
  2. Python 中"变量名贴在值上"而不是"值存储在变量中"，即变量是可以赋给值的标签，指向特点的值
  3. 变量支持同时赋值 x,y,z = 0, 0, 0
  4. 变量可以通过赋值指向不同类型的对象

特别：常量同变量类似，值在生命周期内保持不变，使用全大写字母表示，由于没有内置的常量类型，由程序员维护。

数据类型#

Python 中有 6 种标准数据类型：

  • Number - 数
  • String - 字符串
  • bool - 布尔
  • List - 列表
  • Tuple - 元组
  • Set - 集合
  • Dictionary - 字典

注：布尔类型是整型的子类，单独列出。

数#

Python 中数字有整数（int）、布尔（bool）、浮点数（float）和复数（complex）四种类型 注：

  1. Python 中没有额外的数据类型关键字标识
  2. Python 可对整数执行加减乘除运算
  3. Python 将带小数点的数称浮点数，，运算浮点数的小数位数不确定
  4. 除法结果总是浮点数
  5. 数中可以使用下划线分组，Python 不会打印下划线 100_00_00
  6. 使用 type() 和 isinstance() 方法可以判断变量类型，二者区别在于后者会将子类类型认为为父类类型

布尔#

布尔类型只有 True 和 False 两个值。

在 Python 中所有非零的数字和非空的字符串、列表、元组等都视为 True 。

列表#

列表：一系列按特定顺序排列的元素，支持数字、字符串，嵌套列表等。

语法：以方括号表示列表，并用逗号分隔元素 —— var = [val,val2,...]

列表是有序集合，同数组类似，使用元素位置索引任意元素（索引从 0 开始），同字符串一致。

遍历#

for var in vars:
    ...

range(begin,end，step) 函数可以生成一系列数，配合 list(vars) 函数可以将结果直接转换为列表。

列表解析#

将 for 循环和创建新元素合并为一行，并自动附加新元素：

squares = [value**2 for value in range(1,11)]
# 表达式 value**2 计算平方和，for 循环为表达式提供值，做好赋值给列表

切片#

切片处理列表中的部分元素，语法为指开始和结束元素的索引 —— vars[begin:end] （不包含尾索引）。

切片常用来复制列表 —— new_vars = old_vars[:]，直接 new_vars = old_vars 将二者直接关联，相当与指针。

元组#

元组即不能修改值的列表

语法：tuple = (val1,varl2,...)

元组的操作同列表相似但不能修改其中元素的值，但可以重新定义元组。

集合#

集合是一种无序、可变的数据类型，用于存储唯一的元素。

语法：vars = {key1:val1,...} 获取 set(value)

注：

  1. 集合支持 差集 （-），并集 （|），交集 （&），对称差集（^）
  2. 创建一个空集合必须使用 set()， {} 创建的是空字典

字典#

字典是一系列键值对 —— vars = {key1:val1,...}

字典使用 key 关联 value，使用get(val,false_message) 函数可以访问字典中的值，keys() 函数遍历字典中所有的键，values() 函数返回字典中的所有值。

bytes 类型#

bytes 类型用于处理二进制数据。

使用 b 前缀创建对象，使用 bytes(str, encoding = "utf-8") 函数可将其它类型转换为 bytes 类型，使用 ord(str) 函数将资产转换为整数值。

推导式#

推导式是一种独特的数据处理方式，可以从一个数据序列构建另一个新的数据序列的结构体，适用于生成列表、字典、集合和生成器。

# 列表推导式
multiples = [i for i in range(30) if i % 3 == 0]

# 字典推导式
newdict = {key:len(key) for key in listdemo}

# 集合推导式
setnew = {i**2 for i in (1,2,3)}

# 元组推导式
a = (x for x in range(1,10))

迭代器与生成器#

迭代器#

迭代器可以记住遍历的位置，只能向前不能后退。

字符串、列表或元组都可以创建迭代器，方法 iter() 和 next()。

注：类使用迭代器，需要实现 __iter__() 和 __next() 方法。

生成器#

使用 yield 的函数被称为生成器，生成器函数可以在迭代过程中逐步产生值。

def countdown(n):
    while n > 0:
        yield n
        n -= 1
 
# 创建生成器对象
generator = countdown(5)
 
# 通过迭代生成器获取值
print(next(generator))  # 输出: 5
print(next(generator))  # 输出: 4
print(next(generator))  # 输出: 3
 
# 使用 for 循环迭代生成器
for value in generator:
    print(value)  # 输出: 2 1

装饰器函数#

用于在不修改原函数代码的前提下，动态扩展函数或类的功能。

target_function = decorator_function(target_function)

示例：

def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("执行前")
        func(*args, **kwargs)
        print("执行后")
    return wrapper

@my_decorator
def greet(name):
    print(f"Hello, {name}!")

greet("Alice")

注；如果原函数有参数，需要在 wrapper 中使用 *args, **kwargs。

常用内置装饰器：

  • @staticmethod：定义静态方法
  • @classmethod：定义类方法
  • @property：将方法变为属性

模块#

模块是拓展名为 .py 的文件，包含要导入到程序中的代码
语法：

  • import <name>，导入全部模块
  • from <name> import <func>，导入指定函数 ，* 为全部函数
  • 关键字 as 可以给导入模块指定别名

注：每个模块都有一个 __name__ 属性

  • 如果模块是被直接运行，__name__ 的值为 __main__
  • 如果模块是被导入的，__name__ 的值为模块名

__name__#

在 Python 中，__name__ 和 __main__ 是两个与模块和脚本执行相关的特殊变量。

__name__ 和 __main__ 通常用于控制代码的执行方式，尤其是在模块既可以作为独立脚本运行，也可以被其他模块导入时。

  1. __name__ 变量

    • __name__ 是一个内置变量，用于表示当前模块的名称。
    • 当模块作为主程序运行时：__name__ 的值被设置为 __main__
    • 当模块被导入时：__name__ 的值被设置为模块的文件名

  2. __main__ 的含义

    • __main__ 是一个特殊的字符串，用于表示当前模块是作为主程序运行的
